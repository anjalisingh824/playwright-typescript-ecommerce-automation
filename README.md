# Playwright TypeScript E-Commerce Automation Framework

A UI test automation framework built using **Playwright and TypeScript**, demonstrating Page Object Model, custom Playwright fixtures, reusable components, assertions, HTML reporting, and GitHub Actions.

## Tech Stack

- Playwright
- TypeScript
- Node.js
- Git & GitHub
- GitHub Actions
- HTML Reporting
